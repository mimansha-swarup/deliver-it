# Swalpa Fast

The game is "Swalpa Fast" (ಸ್ವಲ್ಪ ಫಾಸ್ಟ್). "Deliver It" is only the delivery company inside the game:
the jacket, the box, the dark store and the rider's app. The names are in `src/game/brand.ts`.

## Vision

Read [VISION.md](VISION.md) before proposing or building any feature. It says what the game is (the
rider's life first, funny and true moments, freedom later), what it is not, the four questions a
new feature must answer, and what is a priority now, next and later. If a request sits under
"Later" or "Not this game", say so before building it.

## Art direction

Read [ART_DIRECTION.md](ART_DIRECTION.md) before any visual work: buildings, roads, ground, signs,
vehicles, people, lighting, colour or effects. Every visual change follows it, including its two
rules: the same lighting and colour grade apply to everything, and the game must stay smooth on
the "Low" quality setting and on mid-range laptops.
